# Stream 回复批处理：初始实测

[Draft PR #270](https://github.com/eloqdata/lavik/pull/270)，生产二进制 `1e87107e`，对照固定 main `a565d603`。回复片段合并至约 64 KiB，直接序列化已固定页面的字段并转移构建缓冲区。候选还包含独立验证的冷恢复修复；本次前台 Stream 修改限于回复路径。

这些是单轮独立并发扫描，不是配对稳定性结论。全部 XRANGE、XADD MAXLEN 控制点及错误均在链接数据中；三轮大数据读取复测另列于下方，小数据控制复测已完成，100 MiB 写入控制仍待完成。历史 Redis/Valkey 关闭持久化，Kvrocks 关闭 WAL 且配置 80 GiB 缓存，Lavik 使用持久化 SPDK 且没有 payload cache。不能由单点收益宣称整体达到 peers 的水平。
