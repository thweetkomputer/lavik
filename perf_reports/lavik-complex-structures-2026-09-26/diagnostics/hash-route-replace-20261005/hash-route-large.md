# Hash 单路由替换：100 MiB / 1024 B / 500 keys

固定 parent `19496654` 和 candidate `27c65ff9` 的生产二进制，三轮 A/B、B/A、A/B；每个版本独立 RESTORE 同一已核对 SHA-256 的 RDB 数据，再重启测量。每次逐一检查全部 500 keys 的 102400 个字段；总逻辑 payload 约 48.8 GiB。每点 30 秒、pipeline=1，先读取后写入；没有并发编译、测试或 perf。独立路由种子与物理布局可能造成方差。
